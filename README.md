# Reading Tracker (Python + Textual)

A terminal user interface (TUI) app for tracking your reading sessions, progress, and average reading speed.

## Features

- Add books with title and total pages.
- Select a current book from a list.
- Start, pause, and end reading sessions with a built-in timer.
- Save progress by entering stop page at the end of a session.
- Track per-book metrics:
  - current page
  - completion percent
  - total reading time
  - reading speed (minutes per page)
- Track user-level metrics:
  - total reading time
  - average reading speed
  - number of sessions
- Persist all data to JSON files.

## Tech Stack

- Python 3
- [Textual](https://textual.textualize.io/) for the TUI

## Project Structure

- `main.py` - app entry point
- `screens.py` - app screens and main interaction flow
- `widgets.py` - reusable UI widgets (timer, stats, list row, selected book panel)
- `functions.py` - JSON I/O and helper functions
- `constants.py` - file paths and app CSS
- `books/booklist.json` - stored books and per-book stats
- `config/config.json` - global app configuration and ordering
- `sessions/sessions.json` - session storage placeholder (currently initialized but not actively used)

## Installation

1. Clone this repository.
2. Create and activate a virtual environment (recommended).
3. Install dependencies:

```bash
pip install textual
```

## Run

From the project root:

```bash
python3 main.py
```

## Controls

Global:

- `d` - Toggle dark mode
- `q` - Quit app

On modal screens:

- `Esc` - Cancel / go back

## How It Works

1. On startup, the app ensures required JSON files exist.
2. Add books with **New book**.
3. Select a book from the right-side list.
4. Click **Start Reading**.
5. Enter the starting page.
6. Use **Pause** and **Continue** while reading.
7. Click **Save and Exit**, then enter stop page.
8. The app updates:
   - current page
   - progress percent
   - reading time
   - reading speed
   - global totals in config

## Data Format

### Book entry (`books/booklist.json`)

Each book is stored under an ID key (for example `"0"`, `"1"`):

```json
{
  "title": "Example Book",
  "author": null,
  "num_pages": 300,
  "current_page": 42,
  "reading_time": 1800,
  "reading_speed": 1.5,
  "percent": 14.0
}
```

### App config (`config/config.json`)

```json
{
  "ordered_books": [1, 0, 2],
  "sessions": 14,
  "all_reading_time": 152
}
```

## Notes and Current Limitations

- `sessions/sessions.json` is created but not yet used for detailed session history.
- Author input exists in the data model but is not currently collected in the Add Book UI.
- Reading speed is stored as minutes-per-page based on the latest completed session for that book.
- New book IDs are generated by incrementing the last existing key.
